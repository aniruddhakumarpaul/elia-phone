# Device Scope & Isolation Rules

## Target Device
This project applies exclusively to:
- **Device:** Samsung Galaxy A25 5G (`SM-A256E` / `a25x` / `a25xdins`)
- **SoC:** Samsung Exynos 1280 (5nm, 2x Cortex-A78 + 6x Cortex-A55)
- **OS:** Android 16 (API 36), One UI 8.x

## Strict Isolation Policy
1. **Scope Limit:** All work, scripts, tools, and code MUST remain within `smart-hub` workspace.
2. **Out-of-Scope Repositories:** Never inspect, edit, touch, reference, or run commands on POCO F5, BGMI 90 FPS, or unrelated project files.
3. **Safety First:** If any path or tool outside `smart-hub` workspace is encountered, halt and do not interact with it.
